Exercise 1 – Setup via CDN

Bootstrap CSS is linked in <head> and the JS bundle before </body> (see source of this file).

<!-- In <head> -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet"/>

<!-- Before </body> -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
npm install
npm install bootstrap@5.3.3

Exercise 2 – Bootstrap File Structure

bootstrap/
├── css/
│   ├── bootstrap.min.css        ← main stylesheet
│   ├── bootstrap-grid.css       ← grid only
│   └── bootstrap-utilities.css  ← utilities only
└── js/
    ├── bootstrap.min.js         ← no Popper
    └── bootstrap.bundle.min.js  ← includes Popper (recommended)

bootstrap.bundle.min.js includes Popper.js — required for dropdowns, tooltips, and popovers.

Exercise 19 – Sass Customization

# Install Bootstrap + Sass
npm install bootstrap@5.3.3
npm install --save-dev sass

# Project structure
my-project/
├── scss/
│   └── custom.scss
├── css/
└── index.html

# Compile command in package.json
"build-css": "sass scss/custom.scss css/custom.css --watch"
// scss/custom.scss

// 1. Override variables BEFORE importing Bootstrap
$primary: #e63946;
$border-radius: .75rem;
$font-family-base: 'DM Sans', sans-serif;

// 2. Import Bootstrap
@import "../node_modules/bootstrap/scss/bootstrap";

// 3. Custom styles after
.hero {
  background: $primary;
  color: #fff;
  padding: 4rem 2rem;
}
