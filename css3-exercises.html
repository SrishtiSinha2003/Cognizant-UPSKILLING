Exercise 11 – Debug and Test with Dev Tools

  • Open Chrome DevTools with F12 or right-click → Inspect.
  • Use the Elements panel to inspect and live-edit CSS properties.
  • Use the Device Toolbar (Ctrl+Shift+M) to simulate phones and tablets.
  • Check the Network tab — reload the page and confirm styles.css returns status 200.
  • In the Styles pane, crossed-out rules indicate overridden styles. Click any value to edit it live.
